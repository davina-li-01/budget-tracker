## What I'm building

A simple web-based budget tracker that lets users log expenses, categorize them, and see how much money they’ve spent in each category.

## Who it's for / Why

This tool is for me or anyone who wants a quick way to keep track of their spending without using complicated finance apps. It helps users understand where their money is going and stay within their budget.

## Core features

1. Add expenses by entering an amount, category (food, transportation, entertainment, etc.), and optional description
2. View a list of all expenses that updates dynamically when new ones are added
3. See total spending automatically calculated from all logged expenses
4. Filter expenses by category to understand where money is being spent
5. Delete expenses if they were added by mistake
6. Dashboard to breakdown expenses

## What I don't know yet

1. How to store expense data using JavaScript objects or arrays
2. How to update the DOM dynamically when a new expense is added or deleted
3. How to calculate totals automatically whenever the data changes
4. How to use localStorage so expenses stay saved even after refreshing or closing the page
